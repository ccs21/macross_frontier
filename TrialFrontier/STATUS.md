## Macross Trial Frontier 1.0.5

한글 음성 자막 2,772개를 반영한 1.0.5 정식 배포입니다. **프레임 최적화는 계속 진행합니다. 모든 해상도·전투 상황에서 30fps를 보장하는 버전은 아닙니다.**

### 변경 사항
- 그래픽 설정에서 실제 Vulkan/Direct3D 12 렌더러를 선택할 수 있습니다. 다음 기동부터 적용하며 Vulkan은 SPU LLVM, Direct3D 12는 AOT 경로를 사용합니다. OpenGL은 지원하지 않습니다.
- 창 최대화 및 Vulkan 창의 화면 비율 처리를 수정했습니다.
- 전각 공백 때문에 빠진 텍스트 80종을 추가해 총 583항목을 적용합니다. 설명문 줄바꿈과 구분점(·) 글리프를 수정했습니다.
- 능력치·버튼 안내·조작표·일시정지 메뉴·전투 알림·미션 제목 등 이미지 19종을 원본 크기로 한글화합니다. 사용자 ISO에서 로컬 생성하며 원본 이미지를 ZIP에 넣지 않습니다.
- 화면 좌표의 AA 배율 처리와 2D/3D 명령 상태 분리를 수정했습니다. 확인한 격납고의 어긋난 그림자와 설명 패널 대각선 오류가 개선됐습니다.
- 렌더 명령 묶음 처리, 버퍼·텍스처 재사용, 셰이더 캐시와 CPU/SPU 처리 개선을 포함합니다. 기존 무장 분기 수정과 부분 한글화를 유지합니다.
- 설치기가 사용자 ISO에서 준비한 EBOOT로 SPU 코드를 생성하고 컴파일합니다. 기존 설치의 업데이트에도 자동 적용됩니다. Python·Visual Studio·LLVM을 따로 설치할 필요가 없습니다.
- 생성 파일은 실행 폴더의 `spu-ir/`, 캐시는 `cache/`에 저장합니다. 누락·손상·생성 규칙 변경 시 런처가 다시 준비합니다. ISO/ROM 전체의 고정 해시로 판본을 제한하지 않지만 실행 코드 구조가 호환되어야 합니다.

### 설치 / 기존 사용자 업데이트
1. 게임과 런처를 종료합니다.
2. **TrialFrontier-1.0.5-test.zip** 전체판을 새 폴더에 풀거나, 기존 `TrialFrontier.exe`가 있는 폴더에 내부 파일·폴더를 덮어씁니다. 기존 설치 폴더를 삭제하지 마세요.
3. **TrialFrontier.exe**를 실행합니다. 0.1.4 이후 자동 업데이트도 전체판을 사용합니다. 업데이트 직후에는 런처로 한 번 실행해 새 번역·폰트·이미지와 캐시를 다시 준비하세요. 이 과정이 끝나기 전에 내부 게임 실행 파일을 직접 실행하면 이전 한글화가 표시될 수 있습니다.
4. 처음 설치할 때는 **극장판 마크로스 F - 거짓의 가희 - 하이브리드 팩 일본어판(Gekijouban Macross F - Itsuwari no Uta-hime - Hybrid Pack (Japan))의 ISO** 또는 Windows에 마운트한 해당 ISO를 선택합니다.
5. 암호화된 ISO는 사용자가 준비한 디스크 키를 입력합니다. [키 안내](https://ps3.aldostools.org/dkey.html). SPU 코드 생성과 첫 LLVM 컴파일에는 시간이 필요하므로 준비가 끝날 때까지 기다려 주세요.

`save/`, `settings.ini`, 사용자 설치 데이터는 ZIP에 포함하지 않으며 업데이트 시 보존합니다. 설치 완료 후 폴더 전체를 다른 PC로 복사할 수 있습니다. 다른 CPU/GPU에서는 캐시가 다시 생성될 수 있습니다.

### 요구 환경과 남은 문제
- Windows 11 x64, Vulkan 드라이버, AVX2/FMA 지원 CPU. 약 5GB 이상의 여유 공간과 SSD를 권장합니다. 해상도는 우선 기본 720p로 확인하세요.
- **전투 전체 30fps 고정 미달성:** 마지막 유효한 고부하 전투 측정에 14~18fps 구간이 있었습니다. 이후 변경의 전투 전체 성능 향상은 아직 입증하지 못했습니다.
- 첫 진입, 출격, 변신, 다수 적/미사일 교전의 순간 끊김이 남아 있습니다. 캐시 생성으로 모두 해결되지는 않습니다.
- RPCS3 원본과 알토 격납고·1번 미션 일부를 비교했지만, 5번 미션 석양·출격 광원과 근거리 폭발의 밝기는 검증이 남았습니다. 4K와 전체 기체·미션·다른 PC의 검증 완료판이 아닙니다.
- 주요 UI 이미지 19종을 한글화했습니다. 한글 음성 자막 2,772개를 적용하며, 텍스처 업스케일 팩은 포함하지 않습니다.
- 갑작스러운 종료 제보가 있습니다. 해당 로그는 종료 요청에 따른 exit 0이었지만 요청 원인은 미확정입니다. Esc 즉시 종료를 제거하고 종료 요청 경로별 로그를 추가했습니다. 충돌·종료 문제가 모두 해결된 버전이라는 뜻은 아닙니다.
- 다음 작업은 남은 화면 오류 검증 및 수정 후 프레임 최적화입니다.

ROM, ISO, 키, 펌웨어, 개인 세이브, 추출한 SPU 이미지와 생성된 SPU 코드는 배포하지 않습니다. 문제 제보에는 `diagnostics/`의 최신 진단 ZIP, 미션·기체·형태·버튼을 함께 적어 주세요. 진단은 자동 전송되지 않습니다.

### 1.0.0 음성 자막 및 아이콘
- 음성 재생 시작·종료에 맞춘 한글 자막 2,772개를 추가했습니다. 하단의 투명 배경과 검은 외곽선으로 표시합니다.
- 고스트 이름을 시몬·요하네·페테로로 통일했습니다.
- 게임 창과 실행파일에 `trialicon.ico`를 적용했습니다.
- 기존 사용자는 런처 자동 업데이트 후 자막을 자동 적용합니다. 수동 덮어쓰기 후에도 `TrialFrontier.exe`를 한 번 실행하세요.
- ZIP 파일명의 `-test`는 기존 자동 업데이트 프로그램과의 호환을 위해 유지한 이름입니다. 이 릴리즈는 1.0.5 정식 릴리즈입니다.
- 음성의 자동 전사 오인식에 따른 번역 오류가 남아 있을 수 있습니다.

### 1.0.1 런쳐 오류 수정
- 런처 표시 문구를 수정했습니다.
- 프레임 최적화는 계속 진행합니다.

실행은 **TrialFrontier.exe**를 사용하세요. 게임 본체는 첫 실행 시 `runtime/TrialFrontierRuntime.exe`로 준비됩니다. 이전 업데이트 프로그램 호환용 `MacrossTrialFrontier.exe`는 준비 완료 후 자동 정리됩니다. 기존 본체 바로가기는 런처 바로가기로 바꿔 주세요. 세이브·설정·게임 데이터·캐시는 기존 위치를 유지합니다.

인터넷에 연결되어 있지 않으면 업데이트 확인을 건너뛰고 기존 설치 확인 및 게임 실행을 진행합니다.

창 모드의 최대화 여부를 종료 시 저장하고 다음 실행에 복원합니다. 최소화 상태는 시작 상태로 저장하지 않습니다.

### 1.0.5 성능 진단 개선

Vulkan 교전 중 프레임 저하 원인을 확인할 수 있도록 제한된 성능 기록을 추가했습니다. 프레임 개선은 아직 검증 전이며 최적화는 계속 진행합니다. 게임 종료 후 `diagnostics/performance-latest.zip`을 전달하면 분석할 수 있습니다. 자동 전송하지 않습니다. 새 성능 원본은 실행당 합계 약 5.5MB로 제한하며 덮어씁니다. 성능 ZIP은 최신/직전 두 개를 유지하고 기존 일반 진단 로그는 별도입니다. 18,000프레임(30fps 기준 약 10분) 또는 대기 기록 상한에 도달하면 해당 기록을 중단하므로 문제 구간은 실행 초반에 재현해 주세요. Direct3D 12에서는 Vulkan 성능 기록이 생성되지 않습니다.
