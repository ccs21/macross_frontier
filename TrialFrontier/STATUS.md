# 현재 문제와 작업 현황 — 0.1.5

> **0.1.6 테스트 버전:** 미쉘기·루카기 주 무장 및 부스트 정지에 관련된 무장 분기 누락 29개를 수정했습니다. 사용자 직접 플레이 확인 범위로 배포하며 타 PC·전체 미션 검증은 미완료입니다. **전투 중 20fps 미만 하락과 끊김은 미해결**입니다. [릴리즈 설명](https://github.com/ccs21/macross_frontier/releases/tag/v0.1.6).

## 현재 버전과 업데이트

- 무장 분기 누락 29개를 복원한 실행본입니다. 현재 PC 사용자 플레이에서 공격·진행을 확인했으며, 전체 미션과 다른 PC 검증은 미완료입니다.
- 텍스트 한글화는 503항목입니다. 내부 미션 키는 원문으로 보존합니다. 이미지 번역과 음성 자막은 미완료입니다.
- 전투 중 20fps 미만 하락과 순간 끊김이 남아 있습니다. 애니메이션 작업 완료 대기, 기하 처리, 스레드 생성 경로를 분석 중이며 30fps 고정을 보장하지 않습니다.
- 0.1.4 이후 런처는 시작 시 새 전체판 ZIP을 확인하고 SHA-256 검증 후 교체합니다. 0.1.3 또는 자동 확인 실패 시 새 전체판을 직접 받아 덮어쓰세요.
- 게임과 런처를 종료한 뒤 교체하세요. `save/`, `settings.ini`, 사용자 원본과 설치 데이터는 유지합니다. 저장 파일은 별도 백업을 권장합니다.
- 업데이트 준비 파일은 실행 폴더의 `.updates/`에 보관합니다. AppData에 설치하지 않습니다.
- 종료 후 `diagnostics/`에 진단 ZIP을 저장합니다. ROM·키·세이브는 포함하거나 자동 전송하지 않습니다. 문제가 남으면 미션·기체·형태·버튼과 함께 제보해 주세요.

## 확인된 제한

- **새 설치 후 스테이지 첫 진입에서 큰 끊김**이 발생할 수 있습니다. 같은 스테이지에 다시 들어가면 매끄러워지는 차이가 사용자 플레이에서 확인됐습니다.
- 기존 성능 확인은 이미 자원이 준비된 상태의 영향을 받았습니다. 이를 신규 설치 첫 진입 성능으로 일반화할 수 없습니다. 평균 30fps와 순간 멈춤은 별개입니다.
- 설치 시 압축 해제 캐시는 생성하지만, 실행 중 필요한 준비가 모두 끝난다는 뜻은 아닙니다. 셰이더/파이프라인 생성, 파일 읽기, GPU 업로드 등 중 실제 병목은 아직 분리 확인 중입니다. “모두 셰이더 캐시 때문”이라고 확정하지 않았습니다.
- HDD에서 추가적인 읽기 지연이 생길 수 있습니다. SSD 이동은 도움이 될 수 있으나 현재 끊김의 해결을 보장하지 않습니다.
- 부분 한글화 503항목. 이미지 메뉴·미추출 텍스트·음성 자막은 남아 있습니다.
- 텍스처 업스케일은 얼굴 주변 품질 저하와 성능 문제로 배포에서 제외했습니다.
- 그래픽·음성·프레임 타이밍에 미확인 문제가 남아 있을 수 있습니다. 모든 스테이지·하드웨어에서 클리어와 안정적인 30fps를 보장하지 않습니다.
- 0.1.3 한글 경로 수정은 빌드 완료 상태이며, 수정 이후 전체 설치·플레이 회귀 검증은 완료하지 않았습니다.

## 진행 중인 작업 영역

1. **첫 진입 끊김 원인 추적**: 신규 설치/첫 진입과 같은 장면 재진입을 분리하고, 오래 걸린 프레임과 파일 I/O·그래픽 준비·오디오 처리를 비교합니다.
2. **사전 준비 범위 확대**: 추적 결과에 따라 필요한 작업을 설치 또는 출격 전 로딩으로 옮기는 방향입니다. 스테이지별 준비 목록 수집과 워밍업은 아직 완료되지 않았습니다.
3. **프레임 타이밍과 오디오 병행 개선**: 평균 수치 외에 간헐적인 멈춤, 출격·변신·락온·미사일 교전·컷인을 계속 점검할 대상입니다.
4. **번역 누락 조사**: 텍스트 추출 범위를 보완하고 이미지 번역 대상과 구분하는 작업이 남아 있습니다.

특정 PC의 GPU 드라이버 캐시를 복사하면 다른 PC에서도 동일하게 동작한다고 가정하지 않습니다. 배포 가능한 준비 목록과 각 사용자 PC에서 수행해야 할 작업을 구분하는 방향입니다. 일정과 완료 시점을 약속하는 문서는 아닙니다.
