# 무장 분기 복구 도구

사용자가 준비한 ELF의 분기 표를 읽어 기존 로컬 PPU 생성 코드의 무장 분기를 복구하는 개발 도구입니다. 게임 데이터·생성 코드는 포함하지 않습니다. 일반 사용자는 실행할 필요가 없으며 릴리즈 실행파일에 수정이 반영돼 있습니다.

두 스크립트의 `--help`에서 `--elf`, `--sdk`, `--output`, `--check`를 확인하세요. 이 도구는 개발 당시 생성 코드의 청크 이름과 구조를 검사하며 임의의 버전에 무조건 적용되지 않습니다. ps3recomp의 ppu_disasm/ppu_lifter가 필요합니다.

이 저장소는 전체 게임 런타임의 독립적인 클린 빌드 입력을 제공하지 않습니다. 공개 런처 빌드 방법은 ../BUILD.md를 참고하세요.
