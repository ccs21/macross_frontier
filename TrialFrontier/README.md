# Macross Trial Frontier — 0.1.3 테스트 버전

## 다운로드와 실행

[릴리즈 페이지](https://github.com/ccs21/macross_frontier/releases/latest)에서 **TrialFrontier-0.1.3-test.zip**을 받으세요. GitHub가 자동으로 제공하는 `Source code.zip`은 게임 실행 패키지가 아닙니다.

1. ZIP을 쓰기 가능한 폴더에 **모두 압축 해제**합니다. ZIP 안에서 직접 실행하지 마세요. `Program Files` 같은 쓰기 제한 폴더는 피하세요.
2. **TrialFrontier.exe**를 실행합니다. `MacrossTrialFrontier.exe`는 내부 게임 실행 파일이므로 최초 설치·일반 실행에는 런처를 사용하세요.
3. ISO 파일을 선택하거나, Windows에 마운트한 ISO 드라이브를 선택합니다. ISO를 실행 파일 옆 또는 `iso` 폴더에 넣어도 됩니다. 한 개만 있으면 자동 선택합니다.
4. 암호화된 ISO이면 해당 디스크의 **32자리 16진수 키**를 직접 입력합니다. [디스크 키 안내](https://ps3.aldostools.org/dkey.html)를 참고하세요. 키를 포함하거나 자동 다운로드하지 않으며 입력한 키를 파일에 저장하지 않습니다. 이미 복호화된 ISO에는 키를 묻지 않습니다.
5. 게임 파일 추출 → EBOOT 준비 → 한글 폰트·번역 적용 → 압축 해제 캐시 생성을 기다립니다. 영화 데이터와 시스템 업데이트는 복사하지 않습니다.
6. 준비가 끝나면 게임을 실행합니다. 이후에는 설치 파일 무결성을 확인한 뒤 실행합니다. 무결성 확인도 디스크를 읽으므로 저장 장치에 따라 시간이 걸릴 수 있습니다.

ISO를 선택하지 않고 닫아도 다음 실행에 설치 화면이 다시 나옵니다. 설치가 중단되거나 필수 파일이 누락·손상되면 다시 ISO를 선택해 설치하는 과정으로 돌아갑니다. 재설치 과정에서는 기존 저장·설정을 유지합니다. 취소는 현재 준비 단계가 끝난 후 처리될 수 있습니다.

## 필요한 원본

**극장판 마크로스 F - 거짓의 가희 - 하이브리드 팩 일본어판(Gekijouban Macross F - Itsuwari no Uta-hime - Hybrid Pack (Japan))의 ISO**를 준비하세요.

하이브리드 팩 전체 ISO를 선택하면 런처가 필요한 게임 파일을 자동으로 추출합니다.

- ISO9660 목록을 읽을 수 있는 **ISO 파일**, 또는 **Windows에 마운트한 해당 ISO**
- 물리 BD 드라이브, PSN PKG, 임의의 폴더형 롬은 현재 설치 화면에서 지원하지 않습니다.

원본은 사용자가 직접 준비해야 합니다. 원본 게임 다운로드 링크는 제공하지 않습니다.

ISO 안의 `PS3_GAME` 및 존재하는 경우 `PS3_DISC.SFB`를 자동 추출합니다. 직접 `PS3_UPDATE`를 복사할 필요가 없습니다. EBOOT의 `SCE` 헤더는 실행 파일 자체의 암호화 형식으로, 그것만으로 ISO 전체의 디스크 암호화 여부를 판단하지 않습니다.

ROM 전체 해시로 특정 덤프만 허용하지 않습니다. 다만 필수 파일과 실행 구조가 호환돼야 하므로 다른 지역판·수정판 모두를 지원한다는 뜻은 아닙니다. 설치 후 손상 확인에 쓰는 해시는 **사용자가 실제 설치한 파일**에서 생성합니다.

## 실행 환경

- Windows 11 x64, Direct3D 12 지원 GPU. 현재 게임 빌드는 AVX2를 사용하는 x64 환경용입니다.
- 설치·캐시 생성을 위한 약 **3GB 이상 여유 공간**. 선택한 원본에 따라 더 필요할 수 있습니다.
- **SSD 권장**. HDD에서는 파일 읽기 지연이 더해질 수 있습니다. SSD도 첫 진입의 모든 끊김을 해결하지는 못합니다.
- 한글 폰트 생성용 Windows **맑은 고딕 굵게 (`malgunbd.ttf`)**가 필요합니다. 폰트 파일은 배포하지 않습니다.
- Python과 RPCS3를 별도로 설치할 필요는 없습니다. 외부 도구 실행에 필요한 시스템 런타임이 없는 PC는 [Microsoft VC++ x64 런타임](https://aka.ms/vs/17/release/VC_redist.x64.exe)이 필요할 수 있습니다.

## 포터블 폴더와 저장

설치를 완료하면 ISO를 계속 마운트할 필요가 없습니다. **설치 완료된 폴더 전체**를 다른 PC로 복사한 뒤 `TrialFrontier.exe`를 실행하세요. 실행 환경에 따라 셰이더 등이 다시 준비될 수 있으므로 캐시까지 복사해도 첫 실행 성능이 같다고 보장하지 않습니다.

| 경로 | 용도 |
| --- | --- |
| `save/` | 게임 진행 저장. 이동·업데이트 전에 별도 백업 권장 |
| `settings.ini` | 그래픽, 키보드, 게임패드 설정 |
| `disc/`, `EBOOT.elf` | 사용자 ISO에서 생성한 실행 데이터 |
| `localization/ko/` | 사용자 원본과 번역을 바탕으로 생성한 한글 적용 파일 |
| `cache/` | 설치 시 생성하는 압축 해제 캐시 등 |
| `install-state.json` | 설치 완료 및 파일 무결성 정보 |
| `_internal/`, `tools/`, `resources/` | 런처와 설치 도구 구성 요소 |
| `launcher.log` | 게임 실행 로그. 문제 제보 시 참고 |

원본 ISO·실행 데이터·디스크 키·개인 저장 파일이 들어 있는 **설치 완료 폴더를 재배포하지 마세요**. 릴리즈 ZIP은 그러한 데이터를 포함하지 않습니다.

## 그래픽 및 조작

게임 창 상단 메뉴에서 설정합니다.

- **설정 → 그래픽 설정**: 기본 720p, 1080p, 1440p(2K), 2160p(4K), 창 모드. 고해상도는 GPU 부하가 늘어납니다.
- **설정 → 컨트롤 설정**: 키보드와 게임패드 버튼을 동시에 설정할 수 있습니다. 양쪽 스틱 방향 및 변신 입력 포함.
- **정보 → 깃허브 / 버전**, **종료** 메뉴 제공.
- 기본 변신 키: **I / K / J / L** (오른쪽 스틱 방향 대응). START는 Enter입니다.
- **30fps 제한** 적용. 60/120fps 모드는 제공하지 않으며 30fps 고정 성능을 보장하는 단계도 아닙니다.
- 텍스처 업스케일 팩은 품질·성능 문제로 제외했습니다. 관련 설정이 표시되더라도 적용할 팩은 포함하지 않습니다.

## 새 버전으로 교체

별도의 업데이트 패치는 배포하지 않습니다. 새 버전의 **전체판 ZIP**을 받아 게임과 런처를 종료한 뒤, 기존 `TrialFrontier.exe`가 있는 폴더에 내용물을 덮어쓰세요. 압축 해제 시 동일한 이름의 폴더를 한 겹 더 만들지 않도록 확인하세요.

배포본에는 `save/`, `settings.ini`, 사용자 게임 데이터가 없으므로 기존 저장·설정·설치 데이터를 유지합니다. 기존 폴더를 먼저 삭제할 필요는 없습니다. 덮어쓴 뒤 `TrialFrontier.exe`로 실행하세요. 필수 설치 데이터가 누락되거나 손상된 경우에는 ISO를 다시 선택하라는 안내가 나올 수 있습니다.

## 문제 해결


- **RPCS3 VCRUNTIME140 오류**: 0.1.1에서 런처의 DLL 경로가 외부 도구에 전달되던 문제를 수정했습니다. `_internal`의 DLL을 임의로 삭제하지 마세요.
- **설치 결과 검증 실패**: 0.1.2에서 ISO의 대문자 경로를 누락으로 오인하던 문제를 수정했고, 실패한 파일과 사유를 표시하도록 변경했습니다.
- **한글 경로에서 한글 깨짐**: 0.1.3에서 폰트 오버레이 경로 처리를 수정했습니다. 수정 후 모든 경로 조합의 실행 검증은 아직 완료되지 않았습니다. 문제가 계속되면 영문 경로를 임시 우회 방법으로 사용하고 제보해 주세요.
- **일본어가 남아 있음**: 부분 한글화입니다. 현재 번역 423항목을 적용하며 이미지 메뉴, 미추출 문자열, 음성 자막은 미완성입니다.
- **첫 스테이지 진입 끊김**: 현재 알려진 주요 문제입니다. 다음 문서를 확인하세요.

**[현재 문제와 작업 현황](STATUS.md)** · **[런처 소스 빌드 방법](BUILD.md)**

오류 제보에는 버전, 설치 단계/스테이지/장면, 첫 진입인지 재진입인지, CPU·GPU·저장 장치, 오류 문구를 적어 주세요. 로그의 개인 경로를 가리고, 원본 게임이나 키는 첨부하지 마세요.
