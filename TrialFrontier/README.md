# Macross Trial Frontier — 1.0.10

한글 음성 자막 2,772개를 반영한 1.0.10 정식 배포입니다. **프레임 최적화는 계속 진행합니다. 모든 해상도·전투 상황에서 30fps를 보장하는 버전은 아닙니다.**


### 설치 / 기존 사용자 업데이트
1. 게임과 런처를 종료합니다.
2. **TrialFrontier-1.0.10-test.zip** 전체판을 새 폴더에 풀거나, 기존 `TrialFrontier.exe`가 있는 폴더에 내부 파일·폴더를 덮어씁니다. 기존 설치 폴더를 삭제하지 마세요.
3. **TrialFrontier.exe**를 실행합니다. 0.1.4 이후 자동 업데이트도 전체판을 사용합니다. 업데이트 직후에는 런처로 한 번 실행해 새 번역·폰트·이미지와 캐시를 다시 준비하세요. 이 과정이 끝나기 전에 내부 게임 실행 파일을 직접 실행하면 이전 한글화가 표시될 수 있습니다.
4. 처음 설치할 때는 **극장판 마크로스 F - 거짓의 가희 - 하이브리드 팩 일본어판(Gekijouban Macross F - Itsuwari no Uta-hime - Hybrid Pack (Japan))의 ISO** 또는 Windows에 마운트한 해당 ISO를 선택합니다.
5. 암호화된 ISO는 사용자가 준비한 디스크 키를 입력합니다. [키 안내](https://ps3.aldostools.org/dkey.html). SPU 코드 생성과 첫 LLVM 컴파일에는 시간이 필요하므로 준비가 끝날 때까지 기다려 주세요.

`save/`, `settings.ini`, 사용자 설치 데이터는 ZIP에 포함하지 않으며 업데이트 시 보존합니다. 설치 완료 후 폴더 전체를 다른 PC로 복사할 수 있습니다. 다른 CPU/GPU에서는 캐시가 다시 생성될 수 있습니다.


## 다운로드와 실행

[릴리즈 페이지](https://github.com/ccs21/macross_frontier/releases/latest)에서 **TrialFrontier-1.0.10-test.zip**을 받으세요. GitHub가 자동으로 제공하는 `Source code.zip`은 게임 실행 패키지가 아닙니다.

1. ZIP을 쓰기 가능한 폴더에 **모두 압축 해제**합니다. ZIP 안에서 직접 실행하지 마세요. `Program Files` 같은 쓰기 제한 폴더는 피하세요.
2. **TrialFrontier.exe**를 실행합니다. `MacrossTrialFrontier.exe`는 내부 게임 실행 파일이므로 최초 설치·일반 실행에는 런처를 사용하세요.
3. ISO 파일을 선택하거나, Windows에 마운트한 ISO 드라이브를 선택합니다. ISO를 실행 파일 옆 또는 `iso` 폴더에 넣어도 됩니다. 한 개만 있으면 자동 선택합니다.
4. 암호화된 ISO이면 해당 디스크의 **32자리 16진수 키**를 직접 입력합니다. [디스크 키 안내](https://ps3.aldostools.org/dkey.html)를 참고하세요. 키를 포함하거나 자동 다운로드하지 않으며 입력한 키를 파일에 저장하지 않습니다. 이미 복호화된 ISO에는 키를 묻지 않습니다.
5. 게임 파일 추출 → EBOOT 준비 → 한글 폰트·번역 적용 → 압축 해제 캐시 생성을 기다립니다. 영화 데이터와 시스템 업데이트는 복사하지 않습니다.
6. 준비가 끝나면 게임을 실행합니다. 이후에는 설치 파일 무결성을 확인한 뒤 실행합니다. 무결성 확인도 디스크를 읽으므로 저장 장치에 따라 시간이 걸릴 수 있습니다.

ISO를 선택하지 않고 닫아도 다음 실행에 설치 화면이 다시 나옵니다. 설치가 중단되거나 필수 파일이 누락·손상되면 다시 ISO를 선택해 설치하는 과정으로 돌아갑니다. 재설치 과정에서는 기존 저장·설정을 유지합니다. 취소는 현재 준비 단계가 끝난 후 처리될 수 있습니다.

## 필요한 원본

**극장판 마크로스 F - 거짓의 가희 - 하이브리드 팩 일본어판(Gekijouban Macross F - Itsuwari no Uta-hime - Hybrid Pack (Japan))의 ISO**를 준비하세요.

하이브리드 팩 전체 ISO를 선택하면 런처가 필요한 게임 파일을 자동으로 추출합니다.

- ISO9660 목록을 읽을 수 있는 **ISO 파일**, 또는 **Windows에 마운트한 해당 ISO**
- 물리 BD 드라이브, PSN PKG, 임의의 폴더형 롬은 현재 설치 화면에서 지원하지 않습니다.

원본은 사용자가 직접 준비해야 합니다. 원본 게임 다운로드 링크는 제공하지 않습니다.

ISO 안의 `PS3_GAME` 및 존재하는 경우 `PS3_DISC.SFB`를 자동 추출합니다. 직접 `PS3_UPDATE`를 복사할 필요가 없습니다. EBOOT의 `SCE` 헤더는 실행 파일 자체의 암호화 형식으로, 그것만으로 ISO 전체의 디스크 암호화 여부를 판단하지 않습니다.

ROM 전체 해시로 특정 덤프만 허용하지 않습니다. 다만 필수 파일과 실행 구조가 호환돼야 하므로 다른 지역판·수정판 모두를 지원한다는 뜻은 아닙니다. 설치 후 손상 확인에 쓰는 해시는 **사용자가 실제 설치한 파일**에서 생성합니다.

## 실행 환경

- Windows 11 x64, Vulkan 지원 GPU. 현재 게임 빌드는 AVX2를 사용하는 x64 환경용입니다.
- 설치·캐시 생성을 위한 약 **5GB 이상 여유 공간**. 선택한 원본에 따라 더 필요할 수 있습니다.
- **SSD 권장**. HDD에서는 파일 읽기 지연이 더해질 수 있습니다. SSD도 첫 진입의 모든 끊김을 해결하지는 못합니다.
- 한글 폰트 생성용 Windows **맑은 고딕 굵게 (`malgunbd.ttf`)**가 필요합니다. 폰트 파일은 배포하지 않습니다.
- Python과 RPCS3를 별도로 설치할 필요는 없습니다. 외부 도구 실행에 필요한 시스템 런타임이 없는 PC는 [Microsoft VC++ x64 런타임](https://aka.ms/vs/17/release/VC_redist.x64.exe)이 필요할 수 있습니다.

## 포터블 폴더와 저장

설치를 완료하면 ISO를 계속 마운트할 필요가 없습니다. **설치 완료된 폴더 전체**를 다른 PC로 복사한 뒤 `TrialFrontier.exe`를 실행하세요. 실행 환경에 따라 셰이더 등이 다시 준비될 수 있으므로 캐시까지 복사해도 첫 실행 성능이 같다고 보장하지 않습니다.

| 경로 | 용도 |
| --- | --- |
| `save/` | 게임 진행 저장. 이동·업데이트 전에 별도 백업 권장 |
| `settings.ini` | 그래픽, 키보드, 게임패드 설정 |
| `disc/`, `EBOOT.elf` | 사용자 ISO에서 생성한 실행 데이터 |
| `localization/ko/` | 사용자 원본과 번역을 바탕으로 생성한 한글 적용 파일 |
| `cache/` | 설치 시 생성하는 압축 해제 캐시 등 |
| `install-state.json` | 설치 완료 및 파일 무결성 정보 |
| `_internal/`, `tools/`, `resources/` | 런처와 설치 도구 구성 요소 |
| `launcher.log` | 게임 실행 로그. 문제 제보 시 참고 |

원본 ISO·실행 데이터·디스크 키·개인 저장 파일이 들어 있는 **설치 완료 폴더를 재배포하지 마세요**. 릴리즈 ZIP은 그러한 데이터를 포함하지 않습니다.

## 그래픽 및 조작

게임 창 상단 메뉴에서 설정합니다.

- **설정 → 그래픽 설정**: 기본 720p, 1080p, 1440p(2K), 2160p(4K), 창 모드, Vulkan/Direct3D 12 선택. 고해상도는 GPU 부하가 늘어납니다.
- **설정 → 컨트롤 설정**: 키보드와 게임패드 버튼을 동시에 설정할 수 있습니다. 양쪽 스틱 방향 및 변신 입력 포함.
- **정보 → 깃허브 / 버전**, **종료** 메뉴 제공.
- 기본 변신 키: **I / K / J / L** (오른쪽 스틱 방향 대응). START는 Enter입니다.
- **30fps 제한** 적용. 60/120fps 모드는 제공하지 않으며 30fps 고정 성능을 보장하는 단계도 아닙니다.
- 텍스처 업스케일 팩과 해당 설정 항목을 제거했습니다.

## 새 버전으로 교체

별도의 업데이트 패치는 배포하지 않습니다. 새 버전의 **전체판 ZIP**을 받아 게임과 런처를 종료한 뒤, 기존 `TrialFrontier.exe`가 있는 폴더에 내용물을 덮어쓰세요. 압축 해제 시 동일한 이름의 폴더를 한 겹 더 만들지 않도록 확인하세요.

배포본에는 `save/`, `settings.ini`, 사용자 게임 데이터가 없으므로 기존 저장·설정·설치 데이터를 유지합니다. 기존 폴더를 먼저 삭제할 필요는 없습니다. 덮어쓴 뒤 `TrialFrontier.exe`로 실행하세요. 필수 설치 데이터가 누락되거나 손상된 경우에는 ISO를 다시 선택하라는 안내가 나올 수 있습니다.

## 문제 해결


- **RPCS3 VCRUNTIME140 오류**: 0.1.1에서 런처의 DLL 경로가 외부 도구에 전달되던 문제를 수정했습니다. `_internal`의 DLL을 임의로 삭제하지 마세요.
- **설치 결과 검증 실패**: 0.1.2에서 ISO의 대문자 경로를 누락으로 오인하던 문제를 수정했고, 실패한 파일과 사유를 표시하도록 변경했습니다.
- **한글 경로에서 한글 깨짐**: 0.1.3에서 폰트 오버레이 경로 처리를 수정했습니다. 수정 후 모든 경로 조합의 실행 검증은 아직 완료되지 않았습니다. 문제가 계속되면 영문 경로를 임시 우회 방법으로 사용하고 제보해 주세요.
- **일본어가 남아 있음**: 부분 한글화입니다. 현재 텍스트 583항목과 UI 이미지 19종의 한글화를 적용합니다. 원본 로고·제작진 표기는 유지하며, 한글 음성 자막 2,772개를 적용합니다. 원문 미인식·번역 공란 333개는 자막이 없으며, 전체 미션의 모든 재생 경로를 검증한 것은 아닙니다. 다른 미번역이 발견되면 장면과 함께 제보해 주세요.
- **첫 스테이지 진입 끊김**: 현재 알려진 주요 문제입니다. 다음 문서를 확인하세요.

**[현재 문제와 작업 현황](STATUS.md)** · **[런처 소스 빌드 방법](BUILD.md)**

오류 제보에는 버전, 설치 단계/스테이지/장면, 첫 진입인지 재진입인지, CPU·GPU·저장 장치, 오류 문구를 적어 주세요. 로그의 개인 경로를 가리고, 원본 게임이나 키는 첨부하지 마세요.

## SPU 코드 준비와 복구

`resources/spu-build/`의 변환 도구가 설치된 `EBOOT.elf`에서 6개 SPU 코드를 생성합니다. 컴파일러는 함께 제공되며 Visual Studio는 필요하지 않습니다. 생성 실패 시 `spu-build-error.log`를 확인하고 런처를 다시 실행하세요. 게임 원본이 손상된 경우 ISO로 재설치합니다. 생성 도중 종료해도 기존 정상 SPU 파일은 마지막 교체 전까지 유지합니다.

AVX2/FMA 지원 CPU와 Vulkan 지원 그래픽 드라이버가 필요합니다. 현재 알려진 제한은 [STATUS.md](STATUS.md)를 확인하세요.

### 1.0.10 음성 자막 및 아이콘
- 음성 재생 시작·종료에 맞춘 한글 자막 2,772개를 추가했습니다. 하단의 투명 배경과 검은 외곽선으로 표시합니다.
- 고스트 이름을 시몬·요하네·페테로로 통일했습니다.
- 게임 창과 실행파일에 `trialicon.ico`를 적용했습니다.
- 기존 사용자는 런처 자동 업데이트 후 자막을 자동 적용합니다. 수동 덮어쓰기 후에도 `TrialFrontier.exe`를 한 번 실행하세요.
- ZIP 파일명의 `-test`는 기존 자동 업데이트 프로그램과의 호환을 위해 유지한 이름입니다. 이 릴리즈는 1.0.10 정식 릴리즈입니다.
- 음성의 자동 전사 오인식에 따른 번역 오류가 남아 있을 수 있습니다.

실행은 **TrialFrontier.exe**를 사용하세요. 게임 본체는 첫 실행 시 `runtime/TrialFrontierRuntime.exe`로 준비됩니다. 이전 업데이트 프로그램 호환용 `MacrossTrialFrontier.exe`는 준비 완료 후 자동 정리됩니다. 기존 본체 바로가기는 런처 바로가기로 바꿔 주세요. 세이브·설정·게임 데이터·캐시는 기존 위치를 유지합니다.

인터넷에 연결되어 있지 않으면 업데이트 확인을 건너뛰고 기존 설치 확인 및 게임 실행을 진행합니다.

창 모드의 최대화 여부를 종료 시 저장하고 다음 실행에 복원합니다. 최소화 상태는 시작 상태로 저장하지 않습니다.

### 1.0.10 Vulkan 깊이 변환 대기 개선

Vulkan에서 깊이·스텐실 정보를 텍스처로 변환할 때 사용하는 중간 버퍼를 GPU 전용 메모리로 옮겼습니다. CPU에서 사용하지 않는 데이터를 CPU 접근용 메모리로 왕복 복사하던 비용을 줄였습니다. 새 렌더 타깃 초기화도 기존 명령 배치에서 처리해 불필요한 완료 대기를 줄였습니다.

- 1.0.9에서 일부 기기의 그래픽 깨짐이 보고된 GPU 정점 변환은 기본적으로 끄고 기존 CPU 변환 경로로 돌렸습니다. 모든 그래픽 오류가 해결됐다는 의미는 아닙니다.
- PC에서 깊이·스텐실 변환 출력의 픽셀 일치를 확인하고 720p 3스테이지 교전을 시험했습니다. 해당 변환 비용과 GPU 배치 대기는 줄었지만, 전체 평균 FPS와 드랍 횟수의 개선은 이번 비교만으로 입증되지 않았습니다. UMPC 효과는 추가 검증이 필요합니다.
- **프레임 최적화는 계속 진행합니다. 모든 교전에서 고정 30fps를 보장하지 않습니다.** 첫 진입 끊김과 격한 교전의 프레임 저하가 남아 있습니다.
- 30fps 제한, 기존 한글·자막, 세이브·설정 및 일반 성능 기록 기능을 유지합니다. 개발용 GPU 상세 계측은 일반 실행에서 켜지지 않습니다.

기존 사용자는 **TrialFrontier.exe**의 자동 업데이트를 이용하거나 전체판의 내용을 기존 폴더에 덮어쓰세요. 기존 설치 폴더를 삭제하지 마세요. 세이브·설정·게임 데이터를 유지합니다. ZIP 이름의 `-test`는 기존 업데이트 호환용 이름이며 일반 릴리즈로 게시합니다.
