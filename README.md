# Macross Frontier — Windows 포팅 프로젝트

> **1.0.7 정식 버전:** 텍스트 583항목·UI 이미지 19종과 음성 자막 2,772개를 반영했습니다. **종료 제보 조사와 전투 30fps 최적화는 진행 중**입니다. [릴리즈 설명](https://github.com/ccs21/macross_frontier/releases/tag/v1.0.7).

Windows 11에서 마크로스 프론티어 게임을 포터블하게 실행하기 위한 런처·설치 도구입니다.

**[최신 릴리즈 다운로드](https://github.com/ccs21/macross_frontier/releases/latest)** · **[설치 및 사용 방법](TrialFrontier/README.md)** · **[현재 문제와 작업 현황](TrialFrontier/STATUS.md)**

> 현재 버전은 완성판이 아닙니다. 신규 설치 후 스테이지에 처음 들어갈 때 로딩·전투 중 끊김이 크게 발생할 수 있습니다. 같은 스테이지를 다시 진행하면 완화되는 현상이 확인됐으며, 모든 상황에서 30fps를 보장하지 않습니다.

필요한 원본은 **극장판 마크로스 F - 거짓의 가희 - 하이브리드 팩 일본어판(Gekijouban Macross F - Itsuwari no Uta-hime - Hybrid Pack (Japan))의 ISO**입니다. 하이브리드 팩 전체 ISO를 선택하면 런처가 필요한 게임 파일을 자동으로 추출합니다.

이 저장소에 공개하는 범위는 **포팅 런처, ISO 입력·설치, 로컬 한글 적용, 압축 해제 캐시 생성 코드**입니다. 게임 전체 엔진/재컴파일 코드의 공개 저장소는 아닙니다. 원본 게임·ISO·복호화 키·펌웨어·저장 파일은 제공하지 않습니다. 주요 UI 이미지 한글화를 반영했으며, 한글 음성 자막 2,772개를 제공합니다. 프레임 최적화는 계속 진행 중입니다.

게임을 실행할 때 RPCS3 에뮬레이션을 거치는 방식은 아닙니다. 동봉한 RPCS3 도구는 최초 설치 중 EBOOT 실행 파일을 준비하는 용도로만 사용합니다.

공개된 자체 런처·설치 코드에는 MIT 라이선스를 적용합니다. 외부 도구, 원본 게임, 로고·아이콘 등의 권리는 각 권리자에게 있으며 이 라이선스로 재허락하지 않습니다.

실행은 **TrialFrontier.exe**를 사용하세요. 게임 본체는 첫 실행 시 `runtime/TrialFrontierRuntime.exe`로 준비됩니다. 이전 업데이트 프로그램 호환용 `MacrossTrialFrontier.exe`는 준비 완료 후 자동 정리됩니다. 기존 본체 바로가기는 런처 바로가기로 바꿔 주세요. 세이브·설정·게임 데이터·캐시는 기존 위치를 유지합니다.

인터넷에 연결되어 있지 않으면 업데이트 확인을 건너뛰고 기존 설치 확인 및 게임 실행을 진행합니다.

창 모드의 최대화 여부를 종료 시 저장하고 다음 실행에 복원합니다. 최소화 상태는 시작 상태로 저장하지 않습니다.

### 1.0.7 렌더링 중복 처리 개선

같은 렌더 패스에서 변하지 않은 상태 설정 명령을 생략하고, 파이프라인·프레임버퍼·샘플러 반복 조회를 개선했습니다. 조회는 현재 테이블 키를 검증합니다. 동일한 2,000개 그리기 명령의 렌더러 단독 시험에서 처리 시간이 약 32% 감소했고 출력 픽셀이 일치했습니다. 게임 전체 FPS 또는 UMPC의 개선율을 뜻하지 않습니다. CPU·FIFO·SPU·화면 표시 계측은 유지하며 `diagnostics/performance-latest.zip`으로 실제 교전을 비교합니다. 원본 세 파일 약 10.1MB 상한, 최신/직전 성능 ZIP 보관, 자동 전송 없음. 프레임 최적화는 계속 진행합니다.
