# Macross Frontier — Windows 포팅 프로젝트

> **1.0.12 정식 버전:** 텍스트 583항목·UI 이미지 19종과 음성 자막 2,772개를 반영했습니다. **종료 제보 조사와 전투 30fps 최적화는 진행 중**입니다. [릴리즈 설명](https://github.com/ccs21/macross_frontier/releases/tag/v1.0.12).

Windows 11에서 마크로스 프론티어 게임을 포터블하게 실행하기 위한 런처·설치 도구입니다.

> 현재 버전은 완성판이 아닙니다. 신규 설치 후 스테이지에 처음 들어갈 때 로딩·전투 중 끊김이 크게 발생할 수 있습니다. 같은 스테이지를 다시 진행하면 완화되는 현상이 확인됐으며, 모든 상황에서 30fps를 보장하지 않습니다.

필요한 원본은 **극장판 마크로스 F - 거짓의 가희 - 하이브리드 팩 일본어판(Gekijouban Macross F - Itsuwari no Uta-hime - Hybrid Pack (Japan))의 ISO**입니다. 하이브리드 팩 전체 ISO를 선택하면 런처가 필요한 게임 파일을 자동으로 추출합니다.

이 저장소에 공개하는 범위는 **포팅 런처, ISO 입력·설치, 로컬 한글 적용, 압축 해제 캐시 생성 코드**입니다. 게임 전체 엔진/재컴파일 코드의 공개 저장소는 아닙니다. 원본 게임·ISO·복호화 키·펌웨어·저장 파일은 제공하지 않습니다. 주요 UI 이미지 한글화를 반영했으며, 한글 음성 자막 2,772개를 제공합니다. 프레임 최적화는 계속 진행 중입니다.

게임을 실행할 때 RPCS3 에뮬레이션을 거치는 방식은 아닙니다. 동봉한 RPCS3 도구는 최초 설치 중 EBOOT 실행 파일을 준비하는 용도로만 사용합니다.

공개된 자체 런처·설치 코드에는 MIT 라이선스를 적용합니다. 외부 도구, 원본 게임, 로고·아이콘 등의 권리는 각 권리자에게 있으며 이 라이선스로 재허락하지 않습니다.

실행은 **TrialFrontier.exe**를 사용하세요. 게임 본체는 첫 실행 시 `runtime/TrialFrontierRuntime.exe`로 준비됩니다. 이전 업데이트 프로그램 호환용 `MacrossTrialFrontier.exe`는 준비 완료 후 자동 정리됩니다. 기존 본체 바로가기는 런처 바로가기로 바꿔 주세요. 세이브·설정·게임 데이터·캐시는 기존 위치를 유지합니다.

인터넷에 연결되어 있지 않으면 업데이트 확인을 건너뛰고 기존 설치 확인 및 게임 실행을 진행합니다.

창 모드의 최대화 여부를 종료 시 저장하고 다음 실행에 복원합니다. 최소화 상태는 시작 상태로 저장하지 않습니다.

### 1.0.12 텍스처 사전 준비 및 렌더링 처리 개선

원본 2D 압축 텍스처를 게임 파일에서 미리 추출하고, Vulkan 시작 준비 단계에서 GPU에 업로드하도록 변경했습니다. 실제 게임 데이터와 바이트 단위로 일치할 때만 준비된 텍스처를 사용합니다. 플레이를 반복해 캐시를 먼저 쌓을 필요는 없습니다. 고해상도 텍스처 팩 기능이 아닙니다.

- 기존 설치도 업데이트 후 처음 실행할 때 텍스처 준비 파일을 자동으로 만듭니다. 이 과정과 이후 시작 준비 시간이 늘 수 있습니다. 파일 복사·다운로드로 같은 드라이브가 사용 중이면 준비가 더 느려질 수 있습니다.
- 현재 사전 준비 대상은 원본 2D BC1/BC2/BC3 텍스처입니다. 큐브맵·볼륨·비압축·동적 렌더 타깃은 기존 처리 경로를 사용합니다. 로컬 캐시는 최대 256MiB의 원본 텍스처 데이터를 보관하며, GPU 사전 준비로 메모리 사용량이 늘어납니다. 게임에서 갱신된 데이터가 다르면 기존 경로로 처리합니다.
- CPU의 16비트 실수 정점 변환을 SIMD로 처리합니다. 전체 16비트 값과 경계 접근 검사를 통과했습니다. 정점 결과 재사용 실험은 일반 실행 경로에서 제외했습니다.
- PC 전투 기록에서 사전 준비된 텍스처가 최소 96개 재사용된 것을 확인했습니다. 이는 모든 기체·미션 검증 완료나 전체 FPS 개선율의 확정을 의미하지 않습니다.
- **다수의 적·미사일 교전에서 프레임 하락이 남아 있으며, 고정 30FPS는 아직 달성하지 못했습니다. 프레임 최적화는 계속 진행합니다.** CPU 명령 처리와 SPU 작업 지연을 조사하고 있습니다.
- 기존 30FPS 제한, 한글·음성 자막, 포터블 저장·설정 및 자동 업데이트를 유지합니다. 개발용 SPU 상세 계측과 DMA 검사 실험은 일반 실행에서 기본 비활성화합니다.

기존 사용자는 **TrialFrontier.exe**의 자동 업데이트를 이용하거나 전체판의 내용을 기존 폴더에 덮어쓰세요. 세이브·설정·게임 데이터는 유지합니다. ZIP 이름의 `-test`는 기존 업데이트 호환용이며 일반 릴리즈입니다.
